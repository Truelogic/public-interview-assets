# Product Explorer - Visual Frontend Exercise

A **minimal starter** for a visual frontend coding exercise. It includes **HTML and plain JavaScript only**: no CSS, no framework, no build tools and no dependencies.

## Getting started

Open `index.html` in a browser. Edit the files using any editor. You may also serve the folder with a local web server if you prefer.

## Your task

Starting from the unstyled product list, implement the interface shown in the references:

- `references/desktop.png` - desktop layout
- `references/mobile.png` - mobile layout
- `references/interactions.mp4` - interaction and animation examples

Build the visual layout with HTML/CSS, implement the interactions you can within the timebox and make the result responsive. Keep the product data and images available in `app.js` and `assets/` as a starting point. The references show the intended experience; the starting code **does not** provide that layout or behavior.

Use plain JavaScript or switch to React, Vue, Svelte or another framework if you prefer. **Framework migration is optional.** Animation libraries are also optional. You may use AI and documentation while sharing your screen, but be ready to explain and validate your implementation.

Prioritize the visual implementation, responsive behavior, meaningful interactions and a working page. You are not expected to perfect every detail in 60 minutes.

## Files

- `index.html`: minimal HTML page with an empty product list
- `app.js`: product data and simple list rendering
- `assets/`: local product photos
- `references/`: the design and motion targets

The project is intentionally unstyled. There is no CSS file or hidden solution in this repository.
